# 💸 ThinkSpend - Smart Expense Tracker

## 📌 Overview
ThinkSpend is a smart expense tracking web application built using the MERN stack.  
It not only helps users track their expenses but also provides insights, alerts, and financial analysis to improve spending habits.

---

## 🚀 Features

- 🔐 User Authentication (JWT based login/signup)
- 👤 User-specific data (each user sees only their own expenses)
- ➕ Add / Edit / Delete Expenses
- 🗂️ Category system (predefined + custom categories)
- 🔍 Search and Filter (by category, date, and keyword)
- 📊 Interactive Charts (Bar, Pie, Monthly Trend)
- 💰 Budget Management (user-defined budget)
- 📈 Budget Progress Bar
- 🚨 Smart Alerts (budget warning, overspending alerts)
- 🧠 Smart Advice (based on spending behavior)
- 🧮 Money Score (0–100 financial score)
- 🌗 Dark / Light Mode UI

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Chart.js

### Backend
- Node.js
- Express.js

### Database
- MongoDB (Mongoose)

### Authentication
- JWT (JSON Web Token)
- Bcrypt (password hashing)
